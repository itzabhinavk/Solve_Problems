If-Else Conditions

Decision making with if, elif, and else in Python.

age = 18
if age >= 18:
    print("Adult")
else:
    print("Minor")

Loops

OOP Basics

Classes and Objects in Python help build structure.

class Person:
    def __init__(self, name):
        self.name = name

    def greet(self):
        print("Hello", self.name)
