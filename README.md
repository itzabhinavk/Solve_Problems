# Programming Practice

A collection of my daily programming practice, exercises, and small projects. I use this repository to learn by writing code, solving problems, and keeping track of what I work on.

## Folders

- [`C programm/`](./C%20programm/) - C programming exercises.
- [`DSA/`](./DSA/) - Data structures and algorithms practice.
- [`college_lab_practice/`](./college_lab_practice/) - College programming lab exercises.
- [`python/`](./python/) - Python learning, exercises, and projects.

## Current Practice

### Data Structures and Algorithms

[`DSA/Linked_list.py`](./DSA/Linked_list.py) is my current linked-list practice. It demonstrates creating nodes, traversing and printing a list, finding the sum and number of nodes, inserting nodes, and reversing the list.

Run it with Python:

```bash
python DSA/Linked_list.py
```

On Windows, this may also be:

```powershell
py DSA\Linked_list.py
```

## Daily Practice Workflow

1. Add each exercise to the folder that best matches its language or topic.
2. Use a descriptive filename, such as `DSA/Linked_list.py`.
3. Run the program locally and keep useful examples or explanations with the exercise.
4. Save and publish changes regularly:

```bash
git add -A
git commit -m "Add daily programming practice"
git push
```

Generated files such as Python bytecode, virtual environments, and compiled `.exe` files are excluded by `.gitignore`.
